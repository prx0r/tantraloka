# Tantrasāra — English Translation by H.N. Chakravarty

**Translator:** H.N. Chakravarty (1918-2011)
**Editor:** Boris Marjanovic
**Preface:** Swami Chetanananda
**Publisher:** Rudra Press, Portland, 2012
**Source:** Chakravarty's translation of Abhinavagupta's Tantrasāra,
based on the KSTS edition (Bombay: Nirnaya Sagara Press, 1918)

## Purpose

This is a reference translation to compare against DeepSeek's
translation of the same text. Not to be used as training data or
gold standard — only for evaluation of the multipass translation
process.

## Key features

- 22 chapters (Āhnikas)
- Prose summary of Abhinavagupta's Tantrāloka
- Covers: anupāya, śāmbhava, śākta, and āṇava upāyas
- Describes the 36 tattvas, the six paths (ṣaḍadhvas), kalās
- Details: sṛṣṭi, sthiti, saṃhāra, dīkṣā, nyāsa, kula ritual
- Contains extensive notes by Chakravarty and Marjanovic

## Usage

Store in references/sealed/ during blind translation.
Only open for Pass 6 (Comparative Review) and later.
