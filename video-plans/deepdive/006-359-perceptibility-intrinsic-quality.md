# 359 — Perceptibility as an Intrinsic Quality of Nature
**Tantrāloka 10.19–78ab** | Chapter 10: Tattvabheda (Perceptibility Matrix)

## Hook
Is perceptibility a quality of the object or a function of the subject? Mīmāṃsā says it belongs to the object. Abhinavagupta disagrees — but not by making it purely subjective.

## Core Teaching
Perceptibility (*vedyatva*) is an intrinsic quality of the object's nature (*vastudharma*), but it manifests only as a function of the perceiver's consciousness. The object does not "have" perceptibility as a fixed property — it shines differently for each perceiver.

## The Mīmāṃsā Position
- Perceptibility is a quality of the object itself
- The same object is equally perceptible to all perceivers
- Differences in perception are due to defects in the perceiver

## Abhinavagupta's Refutation
- If perceptibility were a fixed property, all perceivers would see the same thing
- But a dog hears sounds humans cannot; a sage sees what an ordinary person cannot
- Perceptibility must therefore be relational — it depends on both object and subject

## The Trika Resolution
Perceptibility is:
1. **Intrinsic to the object's nature** — the object has the potential to be perceived
2. **Actualized by the perceiver** — this potential manifests differently according to the perceiver's level
3. **A manifestation of consciousness** — both perceiver and perceived are modes of the same consciousness

## Why This Matters
This position avoids:
- **Objectivism** (perception is the same for all) — false because of differing experiences
- **Subjectivism** (perception is entirely subjective) — false because the object has its own nature
- **Solipsism** (only my perception exists) — false because different perceivers share the same object

## The Śiva-Sakti Framework
The object's perceptibility = its *śakti* (power to manifest). The perceiver's capacity = his *śakti* (power to perceive). Both are expressions of the one Śiva-Śakti union.

## Connection to Collective Perception (10.83–97ab)
This understanding naturally leads to the question: if perceptibility is relational, how can multiple perceivers experience the same object? The answer is collective perception (*sāmānya vedya*), where the same object manifests differently to different perceivers simultaneously.
