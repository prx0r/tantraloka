# 360 — Collective Perception: One Object, Many Perceivers
**Tantrāloka 10.83–97ab** | Chapter 10: Tattvabheda (Perceptibility Matrix)

## Hook
A show delights an audience — but each spectator enjoys it differently. How can the same performance produce different experiences?

## Core Teaching
One object can be perceived differently by multiple perceivers without contradiction. This is because the object's perceptibility is not a single fixed quality but a range of potentials that actualize according to the perceiver's level.

## Key Verses

**10.83–84**: An object manifests differently when viewed by several perceivers together. Each perceiver sees according to their own nature.

**10.85–88 — A Show Delights an Audience**: The example of a theatrical performance:
- Each spectator enjoys the same show differently
- The actor's skill makes the show accessible to all
- Yet each brings their own sensibility

**10.89–91ab**: Each particular perceptibility (*vedyatva*) performs its own function. The object serves different purposes for different perceivers. Water quenches thirst for humans but is a deadly flood for ants.

**10.91cd–93ab — Definition of Own Nature (*svarūpa*)**: The *svarūpa* of an object is its nature as it is in itself — uncolored by any perceiver. But this "in itself" is never directly experienced; it is only known through perception.

**10.93cd–97ab — Perceptibility, Manifest and Unmanifest**: The perceptibility of an object can be:
- **Manifest** (*vyakta*) — currently being perceived
- **Unmanifest** (*avyakta*) — potential but not actualized
- Both are real aspects of the object

## The Object as Nexus
The object is like a hub around which different perceptions revolve:
- To a Sakala, Earth is solid matter
- To a Pralayākala, Earth is a field of sensations
- To a Vijñānākala, Earth is a configuration of consciousness
- To a Mantra, Earth is a mantra-form
- To Mantreśvara, Earth is a manifestation of Śakti
- To Mantramaheśvara, Earth is a wave in the ocean of I-consciousness
- To Śiva, Earth is none other than Himself

## Philosophical Implications
1. **Relational realism**: objects are real but their reality is relationally determined
2. **Unity of experience**: different perceptions of the same object do not contradict each other
3. **Hierarchical inclusiveness**: higher perceptions include and transcend lower ones

## Connection to the Procedure for Perceivers (10.97cd–113ab)
Having established that one object shines differently for each perceiver, Abhinava now details the precise number of divisions for each perceiver — fifteen for Sakala, thirteen for Pralayākala, eleven for Vijñānākala, etc.
